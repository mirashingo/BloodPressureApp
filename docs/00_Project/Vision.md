# BloodPressureApp Vision

## Vision

**血圧を毎日、気持ちよく記録できるアプリをつくる。**

BloodPressureApp は、医療診断を行うためのアプリではありません。
毎日の血圧記録を「簡単・安心・継続的」に行える体験を提供することを目的とします。

------------------------------------------------------------------------

# Why

既存の血圧記録アプリには次のような課題があります。

-   広告が多く操作に集中できない
-   入力画面が複雑
-   毎日使うにはストレスが大きい
-   データの見返しが分かりにくい

BloodPressureApp は「毎日続けたくなる体験」を最優先に設計します。

------------------------------------------------------------------------

# Target Users

-   高血圧が気になり始めた人
-   毎日血圧を測定している人
-   家族の健康管理をしたい人
-   医師へ測定結果を提出する人

------------------------------------------------------------------------

# Product Principles

1.  数字を最優先に表示する
2.  入力は10秒以内で完了する
3.  片手で操作できる
4.  AIは診断せず、変化を分かりやすく要約する
5.  Flutter・Material 3・Accessibility を前提とする

------------------------------------------------------------------------

# Long-term Goal

血圧管理アプリの決定版となること。

Flutter・Figma・AIを活用した開発プロセスも資産として整備し、
他のヘルスケアアプリにも展開できる設計基盤を構築する。
