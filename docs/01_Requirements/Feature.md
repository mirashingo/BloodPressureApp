# 1. このドキュメントの目的

本ドキュメントは、BloodPressureAppで提供する機能の全体像を定義するための機能概要書です。

機能の詳細仕様は、`FeatureIndex.md` および `Features/` フォルダ内の個別機能仕様書で管理します。

機能は以下の3段階に分類します。

- MVP：初回リリースで提供する基本機能
- Version 2：初回リリース後に追加する拡張機能
- 将来機能：外部サービスやデバイスとの連携を含む中長期的な機能候補

---

# 2. プロダクト目標

BloodPressureAppは、血圧を記録する人が毎日気持ちよく使える、シンプルで継続しやすい血圧管理アプリを目指します。

重視する体験は以下です。

- 血圧を短時間で記録できる
- 過去の記録を簡単に確認できる
- 長期間、無理なく継続できる
- 通院時に医師へ記録を共有しやすい
- 文字サイズや操作方法を利用者に合わせられる
- 複数回測定する人の利用方法にも対応できる

本アプリは、病気の診断、薬の提案、治療方針の判断を行いません。

# 3. MVP機能

## F001 血圧記録

**優先度：P0（必須）**

最高血圧、最低血圧、脈拍、測定日時などを記録します。

### 主な機能

- 最高血圧（SYS）の入力
- 最低血圧（DIA）の入力
- 脈拍（Pulse）の入力
- 測定日時の記録
- 朝・昼・夜などの時間帯分類
- 任意メモの入力
- 記録の保存
- 入力値のバリデーション

### 成功条件

- 基本的な血圧記録を10秒以内で完了できる
- 片手でも操作できる
- オフラインで保存できる
- 保存直後にホーム、履歴、グラフへ反映される

詳細：`Features/F001_BloodPressureRecording.md`

---

**優先度：P0（必須）**

# 4. Version 2候補

個人の記録をもとに、最近の変化を分かりやすい文章で要約します。

AIは診断、治療提案、薬の変更提案を行いません。

## F103 健康メモ

- 体調メモ
- 服薬メモ
- 睡眠メモ
- 運動メモ
- 食事メモ

## F104 複数プロフィール

家族など複数人の記録をプロフィールごとに管理します。

## F105 タグ管理

ユーザーが記録へ任意のタグを設定し、履歴検索や振り返りに使用します。

## F106 表示モード切替

- 標準モード
- 大文字モード
- 大ボタンモード
- シンプルモード
- 高コントラストモード

## F107 複数回測定の集約

- 複数の測定値を1つの測定セッションとして保存
- 全測定値の保存
- 平均値の自動計算
- 採用する測定値の選択
- グラフ・統計で使用する値の設定

# 6. 非機能要件

## パフォーマンス

- 通常環境で3秒以内に起動する
- 血圧記録を1秒以内に保存する
- 履歴を滑らかに表示する
- オフラインでも主要機能を利用できる

## ユーザビリティ

- 基本的な血圧入力を10秒以内で完了できる
- 片手操作を考慮する
- 入力途中で迷いにくい画面構成にする
- 保存完了を明確に伝える

## アクセシビリティ

- Material 3を基本とする
- 十分なタップ領域を確保する
- 動的な文字サイズに対応する
- 色だけに依存しない情報表示を行う
- スクリーンリーダー用ラベルを設定する
- 高齢者でも操作しやすい画面を目指す

## Flutterアーキテクチャ

- Flutter
- Dart
- Material 3
- Riverpod
- GoRouter
- Drift
- Repository Pattern
- Feature-first Structure

# 8. 対象外

BloodPressureAppは以下を行いません。

- 病気の診断
- 高血圧かどうかの断定
- 薬の推奨
- 薬の変更または中止の提案
- 医療従事者に代わる判断
- 緊急性の判定を保証する機能
- AIによる治療方針の提示

---

# 9. 成功指標

- 血圧記録を10秒以内で完了できる
- 毎日の利用に心理的・操作的な負担が少ない
- 高齢者を含む幅広い利用者が操作できる
- 複数回測定の利用方法に対応できる
- 履歴やグラフから測定傾向を理解しやすい
- PDF出力が通院時の記録共有に利用できる
- AIの説明が分かりやすく、医療診断と誤解されない
- Flutter実装がDesign Systemと各機能仕様書に準拠している
