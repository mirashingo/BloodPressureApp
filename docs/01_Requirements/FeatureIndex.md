## 1. このドキュメントの目的

本ドキュメントは、BloodPressureAppで計画・実装する機能を一覧管理するための機能インデックスです。

各機能には一意の機能IDを割り当て、詳細仕様は同じディレクトリ内の個別ファイルで管理します。

このインデックスは、次の用途で使用します。

- プロジェクト全体の機能範囲を確認する
- MVPに含める機能を明確にする
- 機能ごとの優先度と進捗を管理する
- 機能間の依存関係を確認する
- Figma、Flutter実装、テスト仕様を同じ機能IDで関連付ける
- ChatGPT、Codex、Claude CodeなどのAIエージェントへ開発対象を正確に伝える

---

## 2. 機能仕様書の管理方針

機能仕様書は、原則として「1機能 = 1ファイル」で管理します。

```text
docs/
└── 01_Requirements/
    ├── FeatureIndex.md
    ├── Feature.md
    ├── F001_BloodPressureRecording.md
    ├── F002_HomeDashboard.md
    ├── F003_History.md
    ├── F004_Graph.md
    ├── F005_Statistics.md
    ├── F006_Reminder.md
    ├── F007_Export.md
    ├── F008_Backup.md
    └── F009_Settings.md
```

各機能仕様書には、原則として次の項目を記載します。

- 機能ID
- 機能名
- 目的
- ユーザーストーリー
- 対象画面
- 機能要件
- UI・UX要件
- データ項目
- バリデーション
- 状態管理
- 依存機能
- 受け入れ条件
- テスト観点
- 将来拡張
- 対象外事項

## 3. 優先度の定義

| 優先度 | 意味 |
|---|---|
| P0 | MVPに必須。これがないとアプリの主要目的を達成できない |
| P1 | MVPでの実装を強く推奨する重要機能 |
| P2 | 初回公開後の早い段階で追加する機能 |
| P3 | 将来の拡張候補 |
| 保留 | 要件・技術・運用面の検討が必要 |

---

## 4. ステータスの定義

| ステータス | 意味 |
|---|---|
| 未着手 | 詳細仕様の作成前 |
| 仕様作成中 | 個別機能仕様を作成している |
| 仕様確定 | 実装可能な粒度まで仕様が確定している |
| デザイン中 | FigmaでUI・UXを設計している |
| 実装中 | Flutterで実装している |
| テスト中 | Unit、Widget、Integration、UATを実施している |
| 完了 | 受け入れ条件を満たしている |
| 保留 | 判断または外部要因を待っている |

# 8. 機能間の主な依存関係

```text
F001 血圧記録
 ├── F002 ホームダッシュボード
 ├── F003 履歴
 ├── F004 グラフ
 ├── F005 統計
 ├── F007 PDF・CSV出力
 ├── F008 バックアップ・復元
 ├── F101 週間・月間要約
 └── F102 AI傾向要約
```

主な依存関係は以下のとおりです。

| 対象機能 | 依存する機能 | 理由 |
|---|---|---|
| F002 ホームダッシュボード | F001 | 最新記録や本日の記録を表示するため |
| F003 履歴 | F001 | 保存済みの測定記録を表示するため |
| F004 グラフ | F001 | 記録データを時系列で描画するため |
| F005 統計 | F001 | 保存済みデータから統計値を計算するため |
| F007 PDF・CSV出力 | F001、F003 | 記録一覧を抽出・出力するため |
| F008 バックアップ・復元 | F001 | 保存データを保護するため |
| F101 週間・月間要約 | F001、F005 | 記録と集計結果を要約するため |
| F102 AI傾向要約 | F001、F005、F101 | 個人の記録傾向を文章化するため |
| F107 複数回測定の集約 | F001 | 複数の測定値、平均値、代表値、代表値の選択方法を1つの測定セッションとして管理するため |

# 10. アプリが行わないこと

BloodPressureAppは、以下の行為を目的としません。

- 病気や高血圧の診断
- 医療従事者に代わる判断
- 薬の開始、変更、中止の推奨
- 緊急性の自動判定を保証する機能
- 個々の測定値に対する断定的な評価
- AIによる治療方針の提示

測定値の表示や傾向要約を行う場合も、ユーザーを不必要に不安にさせず、医療診断と誤解されない表現を使用します。
