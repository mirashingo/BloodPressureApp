# UserFlow.md

# BloodPressureApp ユーザーフロー

Version: 1.0

------------------------------------------------------------------------

# 目的

BloodPressureAppを利用するユーザーが、

アプリ起動から血圧記録、履歴確認、グラフ・統計確認、

リマインダー設定、データ出力、バックアップ、設定変更までを

迷わず完了できる画面遷移と操作手順を定義する。

本書は、

-   UX設計
-   画面設計
-   Figma作成
-   Flutter実装
-   AIによるコード生成
-   テスト設計

の共通基準として使用する。

------------------------------------------------------------------------

# 対象ユーザー

## 主な利用者

-   毎日血圧を測定する人
-   高齢者
-   通院中の人
-   血圧の変化を記録したい人
-   家族の支援を受けながら利用する人

## 利用上の特徴

-   毎日の短時間操作が中心
-   朝・夜に複数回測定する場合がある
-   大きな文字やボタンを必要とする場合がある
-   医師へ記録を見せる場合がある
-   オフラインで利用する場合がある

------------------------------------------------------------------------

# UX基本方針

-   Homeから主要操作へ1〜2回で移動できる
-   血圧記録を最優先操作とする
-   保存完了を明確に伝える
-   戻る操作で入力内容を失わない
-   重要な削除・上書きは確認を表示する
-   色だけで状態を伝えない
-   医療診断と誤解される表現を使用しない
-   大きな文字でもレイアウトが崩れない
-   片手操作を基本とする

------------------------------------------------------------------------

# 全体フロー

アプリ起動
    ↓
初回起動判定
    ├─ 初回 → オンボーディング → 初期設定 → Home
    └─ 2回目以降 → Home

Home
    ├─ 血圧を記録する → Blood Pressure Input → 確認 → 保存完了
    ├─ 履歴を見る → History → Record Detail → 編集／削除
    ├─ グラフを見る → Graph
    ├─ 統計を見る → Statistics
    ├─ リマインダー → Reminder Settings
    └─ 設定 → Settings
                    ├─ データ出力
                    ├─ バックアップ
                    ├─ 表示設定
                    ├─ 記録設定
                    └─ プライバシー設定

------------------------------------------------------------------------

# UF002 血圧記録フロー

## 開始条件

Homeの「血圧を記録する」を押す。

## フロー


Home
    ↓
Blood Pressure Input
    ↓
測定日時を確認
    ↓
SYS入力
    ↓
DIA入力
    ↓
Pulse入力
    ↓
任意項目入力
    ├─ メモ
    ├─ タグ
    └─ 測定状態
    ↓
入力内容確認
    ├─ 修正する → Blood Pressure Input
    └─ 保存する
            ↓
        保存完了
            ↓
        Home


## 複数回測定


1回目を入力
    ↓
「続けて測定」を選択
    ↓
2回目を入力
    ↓
必要に応じて3回目を入力
    ↓
集約方法を確認
    ├─ 平均
    ├─ 最低値
    ├─ 最終測定値
    └─ 任意選択
    ↓
保存


## 例外フロー

### 入力値エラー


不正な数値
    ↓
該当項目にエラー表示
    ↓
修正
    ↓
保存


### 保存失敗


保存失敗
    ↓
エラー表示
    ├─ 再試行
    └─ 入力内容を保持して戻る


## UX要件

-   数値入力を最優先とする
-   数字キーボードを表示する
-   SYS・DIA・Pulseを明確に区別する
-   入力途中の内容を保持する
-   保存完了を明確に表示する
-   片手で完了できる配置とする

## 関連機能

-   F001 Blood Pressure Recording
-   F002 Home
-   F010 Measurement Continuity
-   F011 Time Period Classification
-   F107 Multiple Measurement Aggregation

MVPでは次の構成を基本とする。

-   Home
-   History
-   Graph
-   Statistics

血圧記録ボタンは

Homeで最も目立つ位置に配置する。

必要に応じて

下部ナビゲーション中央の

Floating Action Buttonとして提供する。

## 戻る操作

-   編集中は入力内容を保持する
-   未保存の場合は確認を表示する
-   モーダルは閉じる操作を明示する

## データなし

データなし
    ↓
空状態
    ├─ 血圧を記録する
    └─ 画面説明を確認する

    ↓

    ↓
記録・編集・削除を継続


## 権限なし

    ↓

    ↓

    └─ キャンセル


## エラー


処理失敗
    ↓
分かりやすいエラー表示
    ├─ 再試行
    ├─ 入力内容を保持
    └─ 安全に前画面へ戻る

# アクセシビリティ

-   タップ領域は十分な大きさを確保する
-   文字拡大に対応する
-   画面読み上げ用ラベルを設定する

# テスト項目

## 正常系

-   初回起動からHomeへ移動できる
-   Homeから血圧記録を完了できる
-   Historyから記録を編集できる
-   Historyから記録を削除できる
-   Graphの期間を変更できる
-   Statisticsの期間を変更できる
-   リマインダーを作成できる
-   PDF・CSVを出力できる
-   バックアップと復元を実行できる
-   設定変更が反映される

## 異常系

-   入力エラーから修正できる
-   保存失敗後に再試行できる
-   データなし状態を表示できる
-   通知権限拒否後も利用できる
-   出力失敗後に再試行できる
-   破損バックアップを拒否できる
-   未保存状態で戻る場合に確認できる

## アクセシビリティ

-   大きな文字でも操作できる
-   画面読み上げで操作できる
-   色覚に依存せず識別できる
-   片手で主要操作を完了できる

# Acceptance Criteria

□ 初回起動からHomeまで迷わず進める

□ Homeから血圧記録を開始できる

□ 血圧記録を少ない操作で保存できる

□ 複数回測定を記録できる

□ Historyから記録詳細を確認できる

□ 記録を編集・削除できる

□ GraphとStatisticsへ移動できる

□ リマインダー通知から入力画面へ移動できる

□ PDF・CSV出力を完了できる

□ バックアップと復元を完了できる

□ Settingsから各設定画面へ移動できる

□ 未保存データの消失を防止できる

□ データなし状態を適切に表示できる

□ オフラインでも主要操作を継続できる

□ 権限拒否後もアプリを利用できる

□ 大きな文字でも主要フローを完了できる

□ 医療診断と誤認される表示を使用しない
