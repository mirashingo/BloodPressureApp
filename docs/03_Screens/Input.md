# SC020 血圧入力（Input）

## 画面ID

SC020

------------------------------------------------------------------------

## 画面名

血圧入力

------------------------------------------------------------------------

## 目的

ユーザーが測定した血圧値を、

少ない操作で正確に入力し、

安全に保存できること。

単回測定だけでなく、

同じ測定機会で2回・3回と測定する利用方法にも対応し、

平均値、最終測定値、任意選択などの集約方法を

ユーザーの設定に応じて扱えることを設計目標とする。

------------------------------------------------------------------------

## ユーザーストーリー

### 基本

私は血圧を測定した利用者として、

収縮期血圧、拡張期血圧、脈拍を

迷わず入力して保存したい。

### 複数回測定

私は同じ時間帯に複数回血圧を測定する利用者として、

1回目、2回目、3回目の値を続けて入力し、

平均値または採用する値を選びたい。

### 補足情報

私は後から測定時の状況を振り返るために、

測定日時、メモ、タグ、測定状態を記録したい。

## UI要件

レイアウト

-   縦スクロールを基本とする
-   SYS、DIA、Pulseを画面上部に配置する
-   数値入力欄を大きく表示する
-   単位を入力欄の近くに表示する
-   主要操作ボタンを画面下部に固定できる構成とする

数値入力

-   数字キーボードを表示する
-   1項目ごとに明確なラベルを表示する
-   SYSとDIAを視覚的に区別する
-   入力後に次の項目へ移動しやすくする
-   値の増減ボタンを補助機能として提供可能とする

測定日時

-   現在日時を初期表示する
-   日付と時刻を分けて確認できる
-   過去日時へ変更できる
-   未来日時は原則入力不可とする

メモ・タグ

-   必須項目より下に配置する
-   折りたたみ可能とする
-   よく使うタグを選択しやすくする

------------------------------------------------------------------------

## UX要件

-   Homeから1回の操作で開ける
-   数値入力を最優先にする
-   必須項目だけで保存可能とする
-   入力途中の内容を保持する
-   保存前に内容を確認できる
-   保存完了を明確に伝える
-   保存失敗時も入力内容を保持する
-   未保存状態で戻る場合は確認を表示する
-   同じ時間帯の追加測定を簡単に開始できる
-   医療診断と誤解される評価を表示しない

## バリデーション

### SYS

-   必須
-   整数
-   設定された許容範囲内
-   DIAより大きいことを基本とする

### DIA

-   必須
-   整数
-   設定された許容範囲内
-   SYSより小さいことを基本とする

### Pulse

-   F009で有効な場合に入力可能
-   整数
-   設定された許容範囲内

### 測定日時

-   必須
-   未来日時は原則不可
-   不正な日時形式を拒否する

### メモ

-   最大文字数を設定する
-   空欄を許可する

### タグ

-   重複選択を許可しない

------------------------------------------------------------------------

## バリデーション表示

-   該当項目の近くにエラーを表示する
-   エラー項目へフォーカスする
-   色だけでエラーを示さない
-   入力済みの他項目は保持する
-   エラー理由と修正方法を表示する

例

```text
SYSを入力してください

SYSはDIAより大きい値を入力してください

未来の日時は選択できません
```

------------------------------------------------------------------------

## 未保存データ

次の場合は未保存状態とする。

-   1項目以上変更した
-   複数回測定を追加した
-   メモまたはタグを変更した

戻る操作時は

```text
入力内容が保存されていません
    ├─ 入力を続ける
    └─ 破棄して戻る
```

を表示する。

------------------------------------------------------------------------

## 保存完了

保存成功時は

-   完了メッセージ
-   保存した測定値
-   測定日時
-   次の操作

を表示する。

次の操作

-   Homeへ戻る
-   続けて測定する
-   記録詳細を見る

------------------------------------------------------------------------

## 保存失敗

保存失敗時は

-   エラー内容
-   再試行
-   入力内容保持
-   安全に戻る操作

を提供する。

データベース保存に失敗した場合は

入力内容を破棄しない。

------------------------------------------------------------------------

## AI対応

AIは

-   入力値を自動で診断しない
-   医療上の危険度を断定しない
-   ユーザーの許可なく健康データを送信しない
-   保存値を無断で変更しない

実施可能な内容

-   メモ入力候補
-   タグ候補
-   入力項目の説明
-   エラー内容の分かりやすい説明
-   複数回測定の集約方法説明

AI提案は

ユーザーが確認して選択した場合のみ反映する。

## キーボード操作

-   SYS入力後にDIAへ移動する

-   最小タップ領域を確保する
